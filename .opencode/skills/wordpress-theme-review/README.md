# WordPress.org Theme Review Skill

Claude Code skill for building and auditing WordPress themes against the official WordPress.org Theme Review Requirements.

## Primary reference

https://make.wordpress.org/themes/handbook/review/required/

## Installation

Copy this entire `wordpress-theme-review` folder into your Claude Code skills directory.

Expected structure:

.claude/
└── skills/
    └── wordpress-theme-review/
        └── SKILL.md

Then instruct Claude Code to use the WordPress Theme Review skill when creating, modifying, or auditing a WordPress theme.

## Important

The official WordPress.org Theme Review Requirements are the source of truth. Review the official handbook for changes before a real WordPress.org submission.
